// TERMUX COMMANDS

Safe local checks

Commands below target only your own phone.

NETWORK INVENTORY · LOCALHOST ONLY

Install Nmap and the local socket viewer, check your phone only, and list services listening on your own device.

pkg install nmap iproute2 -y
nmap -sn 127.0.0.1
ss -ltn

127.0.0.1 means this device itself. Don't replace it with someone else's address or a public IP.
